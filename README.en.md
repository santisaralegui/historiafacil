# Historia Fácil

Web project aimed at making it easier to write medical records in hospital emergency departments.

Lee este README en español: [Español](README.md)

## What problem does it solve?

In the context of hospital emergency shifts, time to write medical records is scarce. On a daily basis, healthcare professionals are faced with writing records that share a similar basic structure, in an environment where time is limited. This project aims to solve this problem by automating the basic structure of medical records and the most frequent repetitions. This would help reduce the time professionals spend on documentation, freeing up more time. Ultimately, this could reduce the time per patient, improving waiting times and quality of care.

## Privacy

Medical records contain sensitive and confidential information, so this project is built using only HTML, CSS, and JavaScript. This allows **all information to be processed locally**, meaning patient data is protected, as it is not transmitted outside the client.

## Usage

Open `index.html` in a web browser.
