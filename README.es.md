# Historia Fácil

Proyecto web pensado para agilizar la redacción de historias clínicas en emergencias hospitalarias.

🔗 **En vivo:** [historiafacil.com](https://historiafacil.com)

Read this README in English: [English](README.md)

## ¿Qué problema resuelve?

Durante las guardias de emergencia, los profesionales de la salud enfrentan alta demanda asistencial y muy poco tiempo para documentar cada consulta. La mayoría de las historias clínicas de baja complejidad comparten una estructura básica similar, pero igual se redactan desde cero cada vez. Historia Fácil automatiza esa estructura repetitiva mediante plantillas predefinidas y editables, reduciendo el tiempo de registro y liberando tiempo para la atención del paciente.

## Privacidad

Las historias clínicas contienen información sensible y confidencial. Este proyecto está construido únicamente con HTML, CSS y JavaScript, de modo que **todo el procesamiento de datos ocurre localmente en el navegador** — la información del paciente nunca se envía a un servidor.

## Cómo funciona

- Aplicación estática, 100% del lado del cliente — sin backend ni base de datos.
- Plantillas predefinidas cubren los tipos de consulta de baja complejidad más frecuentes.
- Los campos son editables antes de generar el texto final de la historia clínica.

## Uso

Abrí `index.html` en un navegador, o usá la versión en vivo en [historiafacil.com](https://historiafacil.com).
